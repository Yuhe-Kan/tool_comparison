The“tool_comparison”directory contains two key components. 

1. The "input data”file  comprises the input data files for these tools, which are produced by the "script.R" code.

2. The "script.R" file is used to generate the input datasets for evaluating the eight tools—METAGENassist, shiny-phyloseq, ampvis2, animalcules, wiSDOM, Mian, Namco, and MicrobiomeAnalyst 2.0.
